How to Add a Game

Want to contribute to Canvas? Follow this guide.

1
Create a GitHub account.
Make an account on GitHub to get started.
2
Get editing permission.
Talk to the Canvas owner to get permission to edit files.
3
Find a game file.
Choose an existing game file to use as a template. Games such as 1v1.lol, Granny, or games with 360-degree movement may need extra code, so ask the owner to add those.
4
Create a new HTML file.
Name it after your game, for example: mygame.html.
5
Paste and customize.
Paste the game code into your new file and change the URL to the game you want.
6
You're done!
Tell the Canvas owner you've added the game so it can be added to the search bar.
